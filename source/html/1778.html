This tutorial quickly explains how to build a a library for the Lattice Mico32 platform. Please refer to the LatticeMico32 Software Developer User Guide, version 8.0, in the chapter "Standard-Make Projects" at page 262 to have further details on how this step has to be accomplished.

First of all it has to be chosen a suitable location for the library since this will have an impact on the creation of conf.oil files, as explained in Tutorial: RT-Druid and OIL basics; for our projects we have chosen the lib_camera_user directory under examples/mico32/demo/sw_projects. In order to create a library you first have to create a microprocessor platform as explained in detail in the User Guide linked above or take a msb file already present in the ERIKA's repository in examples/mico32/demo/platforms/camera_50/soc/camera_50.msb Now launch the LatticeMico32 System as explained in Tutorial: Installing CAL with ERIKA Enterprise and create a new Mico32 Library Project as shown below:
