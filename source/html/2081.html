The Easylab palette:

Symbol Description
This block controls the 4 analog pins of the Easylab board. The internal parameter specifies the pin.
This block controls the Buzzer of the Easylab board. No internal parameters.
This block controls the Microstick led. No internal parameters.
This block controls the digital input pins of the Easylab board. The internal parameter specifies the pin.
This block controls the digital output pins of the Easylab board. The internal parameter specifies the pin.
This block controls the leds of the Easylab board. The internal parameters specify the threshold and the led.
This block controls data sending through the serial interface. The internal parameter specifies the baudrate of the UART controller.
This block controls data reception through the serial interface. The internal parameter specifies the baudrate of the UART controller.
This block controls the 4 PWM pins of the Easylab board. The internal parameters specify the PWM signal frequency and the pin.
This block measures the CPU load and controls the selected PWM output pin of the Easylab board. The internal parameters specify the PWM signal frequency and the pin.
This block measures the CPU load and controls the selected digital output pin of the Easylab board. The internal parameter specifies the pin.
