The FLEX-DemoBoard palette:

Symbol Description
This block maps to an analog input pin of the FLEX Demo Daughter Board. The internal parameter specifies the ADC pin (from 1 to 8).
This block maps to an digital input pin of the FLEX Demo Daughter Board. The internal parameter specifies the GPIO pin (from 1 to 8).
This block maps to a button of the FLEX Demo Daughter Board. The internal parameter specifies the Button (from 1 to 4).
This block maps to the potentiometer analog input of the FLEX Demo Daughter Board. The internal parameter specifies the Potentiometer (from 1 to 4).
This block maps to the encoder input of the FLEX Demo Daughter Board. The internal parameter specifies the encoder (from 1 to 2).
This block maps to the accelerometer input of the FLEX Demo Daughter Board. The internal parameter specifies the Channel (1=x, 2=y, 3=z).
This block maps to the light sensor of the FLEX Demo Daughter Board.
This block maps to the temperature sensor of the FLEX Demo Daughter Board.
This block controls one of the eight LEDs of the Demo Daughter Board. The internal parameter specifies the LED number.
This block controls one of the eight digit output pins of the Demo Daughter Board. The internal parameter specifies the pin.
This block controls the LCD on the Demo Daughter Board.
This block controls one of the two DAC outputs. The internal parameter specifies the DAC channel number. The input is from 0.0 (0.0 V) to 1.0 (3.0 or 5.0 V depending on the HW configuration)
This block controls the buzzer mounted on the Demo Daughter Board. The input value is the frequency of the buzzer sound, in Hz.
This block controls a PWM output of the FLEX Board. The internal parameter specifies the PWM pin (from 1 to 4).
This block controls the LED barrier of the FLEX Board. The internal parameter specifies the threshold.
