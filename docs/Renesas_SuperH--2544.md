# Renesas SuperH

ERIKA Enterprise Manual for Renesas SuperH targets

<a id="Introduction"></a>

## Introduction

This manual describes the porting details of the ERIKA Enterprise kernel(s) for the Renesas families of microcontrollers which supports 32-bit RISC SH-2A cores (aka [SuperH](https://www.renesas.com/en-us/products/microcontrollers-microprocessors/superh.html)).

Due to customer restrictions, this porting is not yet public. If you want to get more information about the SuperH porting, please contact [info@evidence.eu.com](mailto:info@evidence.eu.com).

More details will be available in the near future.
