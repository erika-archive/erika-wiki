# SEED-EYE board

This board is supported by the [Microchip PIC32](Microchip_PIC32--1986.md "Microchip PIC32") porting of Erika.

The board includes a PIC32 microcontroller, an Ethernet interface, a IEEE 802.15.4 adapter, a USB port, and many I/O to connect whatever device you need.
