# Environment problem when running SMCube

On some 64 bit Windows machines, the ScicosLab Pack installer is unable to properly set the environment variables.

If that happens, Simulation and Code generation of SMCube blocks will not work, and an error about the missing environment variable will be displayed.

In that case, You need to manually set the following environment variables:

- SMCUBEPATH
- FLEXPATH
