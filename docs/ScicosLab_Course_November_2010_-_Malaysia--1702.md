# ScicosLab Course November 2010 - Malaysia

This page contains online material, notes and photos about the topics presented in the ScicosLab Training course in Malaysia.

The course has been done by [[Trity Technologies](http://www.tritytech.com/)], which is a company making training in malaysia about model based design including ScicosLab, and the ScicosLab-FLEX toolbox
