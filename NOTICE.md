## Original site declaration

The original Wiki main-page footer states: “Content is available under GNU Free Documentation License 1.2.” The MediaWiki site-info API reports the same rights notice and links to <http://www.gnu.org/licenses/old-licenses/fdl-1.2.txt>.

The complete, unmodified GNU FDL 1.2 text is included as [LICENSE-GFDL-1.2.txt](LICENSE-GFDL-1.2.txt). The API evidence and original main-page HTML are preserved under `metadata/site-info.json` and `source/site-main-page.html`.

## Original attribution and history

Every Markdown page identifies its original title, original URL, source revision, last edit time, contributors recorded in the exported editing history, original MediaWiki source, and the corresponding history export. XML exports preserve original revision records and contributor identities. Uploaded-file records also preserve the original uploader, upload time, comment, source URL, MIME type, dimensions and checksum.

Original per-file descriptions, copyright statements, credits, license declarations, title notices, acknowledgements, dedications and disclaimers are preserved in the archived content and source exports. A site's general footer is not a reason to discard a separate notice attached to an image or third-party file; consult each original file description and source record.

## Archive modifications and history

2026-11-06 to 2026-11-07: the erika-archive preservation project copied the selected public Wiki pages and current original uploads, converted rendered article content to Markdown, rewrote local page/image links, added navigation indexes, and appended archive provenance sections. Article headings were shifted one level below their page title; original MediaWiki anchor identifiers are retained. Source XML, current wikitext and unmodified rendered HTML accompany the converted documents.

Unrelated gift-card/generator spam pages were excluded with the archive owner's approval; only their page inventory is retained. Account-profile namespaces and MediaWiki interface-message namespaces are excluded from project documentation. The source site is not modified by this archive.

The preserved `source/` files provide a transparent source copy alongside the Markdown conversion. Third-party notices are not replaced by a new repository-wide license. The archive does not imply endorsement by the original project, its authors, or resource owners.
